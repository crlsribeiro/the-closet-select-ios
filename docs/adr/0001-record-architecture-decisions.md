# 1. Record architecture decisions

- Status: Accepted
- Date: 2026-11-26

## Context
Decisions about architecture, tools and process need to be traceable for future contributors and reviewers.

## Decision
Use Architecture Decision Records (ADRs) in `docs/adr/`, numbered sequentially, one decision per file: Context, Decision, Consequences.

## Consequences
Every PR that changes the architecture adds or updates an ADR.
